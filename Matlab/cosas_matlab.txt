D:\Programas\MATLAB\R2025b\bin\Matlab.exe

D:\Proyectos\Matlab\Matlab.prj

Si el proyecto no tiene el modulo FGI-GSRx hay que cargalo

Para cargar la configuración en el proyecto
Hay que copiar en la carpeta del proyecto el FGI-GSRx  
Con el comando gsrx se cargan las configuraciones 
params/default_param_TEXBAT_GPSL1.txt

Para procesar el escenario ds3 en el Matlab con FGI-GSRx se utiliza el fichero
complete_Texbat_Dataset-ds3_GPS_L1_CA.txt que hay que configurar con los parámetros que nos interesa

Ejecutar
gsrx('D:\Proyectos\TFG-Hugo\Matlab.old\complete_Texbat_Dataset-ds3_GPS_L1_CA.txt')

Para ejecutar con debug tienes que ir al fichero donde quieras poner el debug y darle a run para que te permita añadirlo al path
